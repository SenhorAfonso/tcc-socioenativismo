# Results accompanying the manuscript

| File | Description |
|------|-------------|
| `simulation_log.txt` | 30-iteration log of the rule-based simulation (Section 4.3, Figure 4 of the manuscript): 23 iterations without action, 3 `sound-` and 4 `light+` interventions. |

Because the simulation draws from the global NumPy random-number generator after the fusion training, the exact trajectory is only reproduced by running the full `python transfer_learning.py` with the same data, seed (`SEED = 42`) and library versions.
